# Circle wave logo

The logo and favicon used before the circle was removed. These are unchanged copies of the original files, retained for reference. The two-wave logo is the selected design and is used in the site header, footer, and favicon.

To restore them, run from the repository root:

```sh
cp design/logo-archive/circle-wave/Logo.svelte src/lib/components/Logo.svelte
cp design/logo-archive/circle-wave/favicon.svg static/favicon.svg
```
